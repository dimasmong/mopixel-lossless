GOOD TO KNOW

Pertanyaan umum

Apakah hasil kompresi benar-benar lossless?+

Untuk PNG, OxiPNG menggunakan optimasi lossless; untuk SVG kami menerapkan pembersihan markup konservatif. Tidak ada resize, pengurangan kualitas JPEG, atau konversi otomatis. Bila tidak dapat mengecilkan dengan aman, file asli dipertahankan.

Kenapa JPEG / HEIC / AVIF saya tidak mengecil?+

Format berbeda membutuhkan optimizer khusus. Versi ini menerima beragam format tetapi hanya mengoptimalkan PNG/APNG dan SVG. Format lain disimpan apa adanya untuk menghindari klaim lossless yang keliru.

Apakah foto saya diunggah ke server?+

Tidak. Pemilihan, pemrosesan, pratinjau, dan file ZIP semuanya dilakukan di browser. Hosting Vercel hanya menyajikan kode situs.

Kenapa terkadang hasil kompresi sama besar?+

Gambar yang sudah dioptimalkan mungkin tidak bisa diperkecil lagi tanpa mengubah datanya. MoPixel tidak pernah mengganti file asli dengan versi yang lebih besar.
